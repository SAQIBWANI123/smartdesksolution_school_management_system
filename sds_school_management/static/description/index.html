📖 Module Overview

The School Management System by SmartDesk Solution is a comprehensive, enterprise-grade Odoo 19 module that brings every aspect of school administration into a single, integrated application. It replaces disconnected spreadsheets, paper registers and standalone tools with structured, searchable digital records.

Built natively on Odoo's framework, it inherits all platform capabilities — user roles, audit logging, chatter messaging, scheduled actions, email notifications and multi-company support — while layering on a complete education-specific data model with 15+ models, 3 PDF reports, analytics dashboards and a configurable timetable engine.

Method A — Odoo App Store (Recommended)

1

Enable Developer Mode

Click the main hamburger menu and select Apps. Remove the default Apps category filter.

Update odoo.conf

Section 4

🔧 Initial Configuration

Complete these steps in the exact order shown. Each step depends on the previous one — for example, you cannot create a Class without a Grade, and cannot enroll a Student without a Class.

1. Create Academic Year

School → Configuration → Academic Years. Set name (e.g. 2026-2027), start/end dates, mark as Current. Optionally add Terms (Semester 1, Semester 2).

2. Create Grade Levels

Configuration → Grade Levels. Add each grade (e.g. Grade 10, code G10). Link curriculum subjects to each grade after subjects are created.

3. Create Subjects

Academics → Subjects & Courses. Add subjects with code, type (Theory / Practical / Both / Elective), pass mark and maximum mark.

4. Create Classes & Sections

Configuration → Classes & Sections. Link each class to a Grade, add section letter (A, B, C), assign Academic Year, Class Teacher and room number.

5. Add Teachers

Faculty → Teachers. Fill qualification, specialization, date of joining, gender, contact details. Use the Teaches Subjects tab to link subjects.

6. Configure Grade Scale

Configuration → Grade Scale. Define letter grades (A+, A, B+, B, C, F) with percentage ranges and GPA points. This drives automatic grading on exam results.

7. Add Parents, then Students

Create parent records first. Then create student records, link them to parents, assign grade, class/section and academic year. Click Enroll Student to move from Draft to Enrolled.

8. Set Up Fee Structures

School Fees → Fee Heads: create fee categories. School Fees → Fee Structures: define amounts per grade per academic year. Generate student invoices from student fee records.

Status Workflow

Each student record moves through a defined lifecycle triggered by action buttons visible at the top of the form:

D

Draft Default

New student record created but not yet formally enrolled. Attendance and fees are not generated yet.

E

Enrolled Active

Click Enroll Student. The student is now active in the system — attendance can be recorded, fees generated, library books issued.

P

Promoted

Student successfully completed the academic year and is promoted to the next grade.

G

Graduated

Student has completed all grades and graduated from the school.

S

Suspended Inactive

Student is temporarily or permanently suspended. Click Suspend on the form.

Section 9

🏫 Academic Structure

The academic structure is the backbone of the entire module. It must be configured before any students, attendance, exams or fees can be created.

school.academic.year

Academic Year

  • Name, Code, Start Date, End Date
  • Active / Current flags (only one year can be current)
  • On change of Current = True, all other years are automatically de-flagged
  • Contains multiple Terms
school.academic.term

Terms / Semesters

  • Name, Code, Start Date, End Date
  • Belongs to one Academic Year
  • Used to filter exams and timetables by term
school.grade

Grade Levels

  • Name, Code, Sequence (controls display order)
  • Many2many link to curriculum Subjects
  • Lists all Classes under this grade
school.class

Classes & Sections

  • Auto-computed name: "Grade 10 - A (2026-2027)"
  • Linked to Grade, Section, Academic Year, Class Teacher
  • Room Number and Capacity
  • Lists all enrolled students (One2many)
  • Subject Allocations tab

✅ Attendance Tracking

The attendance module creates a daily register per class. Teachers can auto-load all enrolled students with a single click, mark statuses, and submit/lock the register for the day.

school.attendance

Attendance Register

  • Date (default: today)
  • Class / Section (required)
  • Teacher / Staff (required)
  • Present Count & Absent Count (computed)
  • Status: Draft → Submitted
school.attendance.line

Per-Student Record

  • Student (required)
  • Roll Number (auto-filled from student)
  • Status: Present / Absent / Late / Excused
  • Remarks (optional free text)
Auto-Load Action

Load Students Button

  • Click Load Students on the register
  • All enrolled students in the selected class are added automatically
  • Default status set to Present
  • Teacher can then change individual statuses
ℹ️
Attendance Percentage CalculationEach student's attendance percentage displayed on their smart button is computed from all school.attendance.line records. Present and Late are counted as attended; Absent and Excused are counted as missed.

🔐 Access Rights & Security

The module defines 4 security groups in school_security.xml. Assign them via Settings → Users & Companies → Users.

Group Technical Name Access Level
School / Student Portal level group_school_student Read-only access to own student record and results via portal
School / Parent or Guardian Portal level group_school_parent Read-only access to linked children's records via portal
School / Teacher or Faculty Internal user group_school_teacher Read students in own class; create/submit attendance; enter exam marks. Implies base internal user rights.
School / Administrator Full access group_school_manager Full CRUD access to all school records, configuration, reports and dashboards. Implies Teacher rights.
💡
Administrator inherits TeacherThe Administrator group uses implied_ids to automatically include all Teacher permissions. You only need to assign one group per user — not both.

🛠️ Troubleshooting

Issue Likely Cause Solution
Module not visible in Apps Addons path not set or apps list not refreshed Add module folder path to addons_path in odoo.conf, restart Odoo, then click Apps → Update Apps List
School Management menu missing User has no school group assigned Assign School / Administrator or School / Teacher role under Settings → Users
Class field empty / no options Grade not selected first, or no classes created Select the Grade Level first — class list is domain-filtered by grade. Then create classes under Configuration.
Load Students button does nothing Class has no enrolled students Enroll students into the class first (change their status from Draft to Enrolled)
Exam result percentage is 0 No marks entered in subject lines Open the Exam Result form, go to Subject Marks tab, add lines for each subject and enter obtained marks
Fee Invoice Amount Due not updating Computed fields not re-triggered Save the record and re-open. If still wrong, run odoo shell and call rec._compute_amounts() manually or upgrade the module.
PDF report gives blank output QWeb template not finding data Ensure the related record has all required fields filled. Check Odoo logs at /var/log/odoo/ for QWeb render errors.
Module upgrade breaks data New version has model changes Always backup database before upgrading: pg_dump dbname > backup.sql. Then run odoo -u school_management.
Available copies shows wrong count Stored computed field cache stale Force recompute: go to the book record and save. Or run module upgrade to recompute all stored fields.
