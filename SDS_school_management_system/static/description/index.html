Generate structured academic results with student details, academic year, registration information, class/section, subjects, maximum marks, pass marks, obtained marks and result status.

15 • Installation

Quick Installation

  1. Copy the module into your Odoo custom addons directory.
  2. Make sure the custom addons path is included in Odoo configuration.
  3. Restart the Odoo server.
  4. Activate developer mode and update the Apps list.
  5. Search for School Management System and install the module.
  6. Configure academic years, classes, subjects and school records.
