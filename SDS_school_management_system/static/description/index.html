05 · Installation

📦 Install in a few steps

1
Enable Developer Mode Open Settings → General Settings → Developer Tools and activate developer mode.
2
Open Apps Open the Apps menu and remove the default Apps category filter if necessary.
3
Search the module Search for School Management System by SmartDesk Solution and click Install.
4
Verify The School Management menu should appear after installation is complete.
💡  Manual installation: For a ZIP installation, place the module in your custom addons path, restart Odoo, update the Apps list and install it from Apps.
