04 · Installation

📦Install in a few steps

1
Enable Developer ModeOpen Settings → General Settings → Developer Tools and activate developer mode.
2
Open AppsOpen the Apps menu and remove the default Apps category filter if necessary.
3
Search the moduleSearch for School Management System by SmartDesk Solution and click Install.
4
VerifyThe School Management menu should appear after installation.
Manual installation: For a ZIP installation, place the module in your custom addons path, restart Odoo, update the Apps list and install it from Apps.
05 · Quick Setup

🧭Recommended configuration order

Set up the academic foundation first, then add people and operational records.

1. Academic YearCreate the current year and terms.
2. GradesDefine grade levels and curriculum.
3. SubjectsAdd subjects and grading rules.
4. ClassesCreate sections and assign teachers.
5. TeachersAdd faculty and subject links.
6. StudentsAdd parents, students and enrollment.
7. FeesConfigure fee heads and structures.
8. OperationsStart attendance, exams and daily workflows.
